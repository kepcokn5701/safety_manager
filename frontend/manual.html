1. 시스템 개요

KEPCO 경남본부 안전재난부에서 운영하는 폭염 안전관리 시스템입니다.

기상청 날씨 데이터를 기반으로 옥외 공사현장의 폭염 위험도를 모니터링하고, 작업자에게 실시간으로 경보를 발송합니다.

구분내용
관리자 앱안전재난부 + 각 지사 담당자. 현장 등록, 날씨 확인, 알림 발송
작업자 앱현장 작업자가 QR 스캔으로 접속. 해당 현장 날씨 + 푸시 알림 수신
알림 채널웹 푸시 (SMS 추가 예정)
날씨 데이터기상청 단기예보 API (5km 격자, 15분 자동 갱신)

2. 일일 업무 흐름

1

사전신고 엑셀 추출

사내망 > 작업안전실적입력시스템 > 사전신고시스템 접속

금일 작업 대상 현장을 조회하여 엑셀 파일(.xls/.xlsx)로 다운로드

↓
2

사외망 반출

FTC(파일전송시스템)를 통해 사내망 → 사외망으로 엑셀 파일 반출

↓
3

안전관리 시스템에 등록

관리자 앱 접속 → "+ 현장 등록" → 엑셀 업로드

담당 사업소 입력 (예: 통영전력지사), 작업강도 선택 → "일괄 등록"

주소 → 좌표 자동 변환 (카카오 Maps API)

↓
4

날씨 확인

"새로고침" 클릭 → 기상청에서 각 현장 날씨 조회

체감온도 기준으로 폭염 단계 자동 판정 (관심/주의/경고/위험)

↓
5

단계별 필터링 + 알림 발송

필터 버튼으로 [위험] [경고] [주의] 등 단계별 필터링

"선택 발송" → 대상 현장 체크 → 해당 현장 작업자에게 알림

또는 "전체 발송"으로 모든 현장에 일괄 발송

↓
6

공지사항 발송 (필요 시)

"공지 발송" → 제목/내용 작성 → 전체 또는 특정 현장 → 발송

작업 중지 안내, 긴급 공지 등

최초 1회 설정 (현장 작업자용)

1

QR 코드 배포

관리자 앱에서 현장별 "QR" 버튼 → QR 코드 생성 → 현장 게시 또는 단톡방 공유

↓
2

작업자가 Chrome으로 QR 스캔 → "알림 허용" 클릭

이후 폭염 경보 + 공지사항을 푸시 알림으로 자동 수신

3. 관리자 앱 사용법

3-1. 접속

!

사업소 선택

첫 접속 시 담당 사업소를 입력하거나 목록에서 선택

"전체 (경남본부)" → 모든 현장 / 특정 지사 → 해당 지사 현장만

헤더의 "사업소 변경"으로 언제든 전환 가능

3-2. 현장 등록

1

"+ 현장 등록" → 엑셀 업로드

사전신고 엑셀 파일 선택 → 현장명/주소 컬럼 매핑

2

담당 사업소 + 작업강도 설정

담당 사업소: 해당 현장을 관리하는 사업소 입력 (예: 통영전력지사)

작업강도: WBGT 기반 권고사항에 영향 (경/중등/중/초중작업)

3

"일괄 등록"

주소→좌표 자동변환 후 등록. 작업자도 자동 추출하여 함께 등록

3-3. 알림 발송

1

"새로고침" → 날씨 조회

같은 5km 격자 현장은 1회만 조회 (병렬 처리로 최적화)

2

필터링 → 발송

[위험(3)] 필터 클릭 → 위험 현장만 표시 → "선택 발송" 또는 "전체 발송"

발송 시 해당 현장에 QR 등록한 작업자에게 푸시 알림 전달

관리자에게는 "발송 완료 - N건 처리" 요약 알림 1건

3-4. 공지사항 / QR 코드

!

공지 발송

"공지 발송" → 제목/내용 작성 → 전체 또는 특정 현장 → 작업자 앱에 파란색 팝업

!

QR 코드

현장 카드의 "QR" 버튼 → QR 이미지 + URL 생성 → 작업자에게 전달

4. 작업자 앱 사용법

!

필수 조건

Android: Chrome 브라우저 (삼성 인터넷 미지원)

iPhone: Safari > 홈 화면에 추가 (iOS 16.4 이상)

1

Chrome으로 QR 스캔 → 현장 날씨 확인

해당 현장의 현재 기온, 체감온도, 습도, WBGT, 조치사항 표시

2

"알림 허용" → "알림 설정 완료" 확인

이후 앱을 닫아도 폭염 알림 + 공지사항이 푸시로 도착

5. 폭염 단계 기준

고용노동부 옥외작업자 온열질환 예방 가이드 기준

단계체감온도주요 조치
관심33°C 이상건강 상태 확인, 수분 섭취 권고
주의35°C 이상2시간 주기 휴식, 그늘 휴식공간 확보
경고38°C 이상1시간 주기 휴식, 무거운 작업 금지
위험41°C 이상즉시 작업 중지, 근로자 대피

6. 문제 해결

증상해결
현장 목록 안 보임"새로고침" 클릭 (날씨 조회에 수 초 소요)
작업자 알림 안 감작업자가 QR 스캔 → Chrome → 알림 허용 필요
"발송 대상 없음"작업자 앱에서 알림 OFF→ON 재시도
삼성 인터넷 알림 불가Chrome 브라우저로 접속
iPhone 알림 불가Safari > 공유 > 홈 화면에 추가 > 앱에서 알림 허용
엑셀 업로드 실패.xls .xlsx .csv만 지원 (10MB 이하)
