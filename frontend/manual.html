1. 시스템 개요

KEPCO 경남본부 안전재난부에서 운영하는 폭염 안전관리 시스템입니다.

기상청 날씨 데이터를 기반으로 옥외 공사현장의 폭염 위험도를 모니터링하고, 작업자에게 실시간으로 경보를 발송합니다.

구분내용
관리자 앱안전재난부 + 각 지사 담당자. 현장 등록, 날씨 확인, 알림 발송
작업자 앱현장 작업자가 QR 스캔으로 접속. 해당 현장 날씨 + 푸시 알림 수신
알림 채널웹 푸시 (SMS 추가 예정)
날씨 데이터기상청 단기예보 API (5km 격자, 15분 자동 갱신)

1-1. 좌표 변환 및 날씨 조회 구조

이 시스템은 카카오맵 API와 기상청 API 두 가지 외부 서비스를 사용합니다. 각각의 역할과 좌표가 어떻게 연결되는지 설명합니다.

전체 흐름 (한눈에 보기)

엑셀의 도로명주소 (예: "경상남도 통영시 중림2로 25")
    ↓ 카카오맵 Geocoding API
WGS84 좌표 (위도: 34.8544, 경도: 128.4331)
    ↓ Lambert 정각원추 변환 공식
기상청 격자좌표 (nx: 91, ny: 67)
    ↓ 기상청 단기예보 API
기온 28°C, 습도 75%, 풍속 2.1m/s
    ↓ 체감온도 계산 (Heat Index)
체감온도 31.2°C → 정상 단계

Step 1: 카카오맵 Geocoding API (주소 → 좌표)

!

역할: 도로명주소를 GPS 좌표(위도/경도)로 변환

엑셀에 있는 공사현장 주소는 사람이 읽는 텍스트입니다. 날씨를 조회하려면 숫자로 된 좌표가 필요합니다.

항목내용
API 제공자카카오 (Kakao Developers)
사용 API로컬 > 주소 검색 (Address Search)
입력"경상남도 통영시 중림2로 25" (도로명주소)
출력위도: 34.8544, 경도: 128.4331 (WGS84 좌표계)
좌표계WGS84 (EPSG:4326) - GPS, 구글맵, 네이버지도 등 전 세계 공통 좌표계
정밀도건물 단위 (~1m 이내)
호출 시점현장 등록 시 1회 (좌표는 DB에 저장되어 재사용)
i

WGS84 좌표란?

지구 위의 위치를 위도(latitude)와 경도(longitude) 두 숫자로 표현하는 방식입니다.

예: 서울시청 = 위도 37.5665, 경도 126.9780

GPS 내비게이션, 구글맵, 카카오맵 모두 이 좌표계를 사용합니다.

Step 2: 좌표 변환 (WGS84 → 기상청 격자)

!

역할: GPS 좌표를 기상청이 사용하는 격자 좌표(nx, ny)로 변환

기상청은 전국을 5km × 5km 격자로 나누어 날씨를 예보합니다. 각 격자에 (nx, ny) 번호가 부여되어 있으며, 같은 격자 안의 모든 지점은 동일한 날씨 데이터를 갖습니다.

항목내용
변환 방법Lambert 정각원추 도법 (기상청 공식 변환 공식)
입력위도 34.8544, 경도 128.4331 (WGS84)
출력nx: 91, ny: 67 (기상청 격자좌표)
격자 크기약 5km × 5km
전체 격자 수약 253 × 149 = ~37,000개 (한반도 전체)
연산 위치서버에서 자동 변환 (카카오맵·기상청 API 호출 불필요)
!

5km 격자의 의미

같은 격자 안에 있는 공사현장은 모두 동일한 날씨 데이터를 받습니다.

예: 통영시 중림2로 25와 통영시 중림2로 100은 같은 격자 → 같은 날씨

이 시스템은 같은 격자의 현장을 자동으로 묶어 1회만 API를 호출합니다 (20개 현장이 3개 격자에 있으면 3회만 호출).

Step 3: 기상청 단기예보 API (격자 → 날씨)

!

역할: 격자좌표(nx, ny)로 해당 지점의 현재 기온, 습도, 풍속 조회

기상청 API허브(apihub.kma.go.kr)의 단기예보조회 서비스를 사용합니다.

항목내용
API 제공자기상청 API허브 (apihub.kma.go.kr)
사용 API단기예보조회 (getVilageFcst)
입력nx: 91, ny: 67, 발표일시
출력 항목TMP(기온°C), REH(습도%), WSD(풍속m/s)
발표 주기하루 8회 (02, 05, 08, 11, 14, 17, 20, 23시)
예보 제공발표 후 약 10분 뒤부터 제공
호출 시점"새로고침" 버튼 클릭 시 + 15분 자동 갱신 (스케줄러)

Step 4: 체감온도 및 WBGT 계산

!

기상청 데이터를 받은 후 서버에서 추가 계산

기상청은 기온/습도/풍속만 제공하므로, 체감온도와 WBGT는 서버에서 계산합니다.

지표계산 방법용도
체감온도
(Heat Index)		 기온 + 습도 기반 회귀식
(미국 NWS 공식)		 폭염 단계 판정 기준
33°/35°/38°/41°C
WBGT
(습구흑구온도)		 기온 + 습도 + 풍속
기반 추정 공식		 작업강도별 휴식 권고
(고용노동부 기준)
i

체감온도 예시

기온 33°C + 습도 70% → 체감온도 약 40°C (경고 단계)

기온 33°C + 습도 40% → 체감온도 약 33°C (관심 단계)

같은 기온이라도 습도에 따라 체감온도와 폭염 단계가 달라집니다.

전체 데이터 흐름 요약

단계입력처리출력
1. 주소→좌표도로명주소카카오맵 API위도, 경도 (WGS84)
2. 좌표→격자위도, 경도Lambert 변환 (서버)nx, ny (기상청 격자)
3. 격자→날씨nx, ny기상청 API기온, 습도, 풍속
4. 날씨→단계기온, 습도Heat Index (서버)체감온도 → 폭염 단계
5. 단계→알림폭염 단계웹 푸시 / SMS작업자에게 경보 전달

2. 일일 업무 흐름

1

사전신고 엑셀 추출

사내망 > 작업안전실적입력시스템 > 사전신고시스템 접속

금일 작업 대상 현장을 조회하여 엑셀 파일(.xls/.xlsx)로 다운로드

↓
2

사외망 반출

FTC(파일전송시스템)를 통해 사내망 → 사외망으로 엑셀 파일 반출

↓
3

안전관리 시스템에 등록

관리자 앱 접속 → "+ 현장 등록" → 엑셀 업로드

담당 사업소 입력 (예: 통영전력지사), 작업강도 선택 → "일괄 등록"

주소 → 좌표 자동 변환 (카카오 Maps API)

↓
4

날씨 확인

"새로고침" 클릭 → 기상청에서 각 현장 날씨 조회

체감온도 기준으로 폭염 단계 자동 판정 (관심/주의/경고/위험)

↓
5

단계별 필터링 + 알림 발송

필터 버튼으로 [위험] [경고] [주의] 등 단계별 필터링

"선택 발송" → 대상 현장 체크 → 해당 현장 작업자에게 알림

또는 "전체 발송"으로 모든 현장에 일괄 발송

↓
6

공지사항 발송 (필요 시)

"공지 발송" → 제목/내용 작성 → 전체 또는 특정 현장 → 발송

작업 중지 안내, 긴급 공지 등

최초 1회 설정 (현장 작업자용)

1

QR 코드 배포

관리자 앱에서 현장별 "QR" 버튼 → QR 코드 생성 → 현장 게시 또는 단톡방 공유

↓
2

작업자가 Chrome으로 QR 스캔 → "알림 허용" 클릭

이후 폭염 경보 + 공지사항을 푸시 알림으로 자동 수신

3. 관리자 앱 사용법

3-1. 접속

!

사업소 선택

첫 접속 시 담당 사업소를 입력하거나 목록에서 선택

"전체 (경남본부)" → 모든 현장 / 특정 지사 → 해당 지사 현장만

헤더의 "사업소 변경"으로 언제든 전환 가능

3-2. 현장 등록

1

"+ 현장 등록" → 엑셀 업로드

사전신고 엑셀 파일 선택 → 현장명/주소 컬럼 매핑

2

담당 사업소 + 작업강도 설정

담당 사업소: 해당 현장을 관리하는 사업소 입력 (예: 통영전력지사)

작업강도: WBGT 기반 권고사항에 영향 (경/중등/중/초중작업)

3

"일괄 등록"

주소→좌표 자동변환 후 등록. 작업자도 자동 추출하여 함께 등록

3-3. 알림 발송

1

"새로고침" → 날씨 조회

같은 5km 격자 현장은 1회만 조회 (병렬 처리로 최적화)

2

필터링 → 발송

[위험(3)] 필터 클릭 → 위험 현장만 표시 → "선택 발송" 또는 "전체 발송"

발송 시 해당 현장에 QR 등록한 작업자에게 푸시 알림 전달

관리자에게는 "발송 완료 - N건 처리" 요약 알림 1건

3-4. 공지사항 / QR 코드

!

공지 발송

"공지 발송" → 제목/내용 작성 → 전체 또는 특정 현장 → 작업자 앱에 파란색 팝업

!

QR 코드

현장 카드의 "QR" 버튼 → QR 이미지 + URL 생성 → 작업자에게 전달

4. 작업자 앱 사용법

!

필수 조건

Android: Chrome 브라우저 (삼성 인터넷 미지원)

iPhone: Safari > 홈 화면에 추가 (iOS 16.4 이상)

1

Chrome으로 QR 스캔 → 현장 날씨 확인

해당 현장의 현재 기온, 체감온도, 습도, WBGT, 조치사항 표시

2

"알림 허용" → "알림 설정 완료" 확인

이후 앱을 닫아도 폭염 알림 + 공지사항이 푸시로 도착

5. 폭염 단계 기준

고용노동부 옥외작업자 온열질환 예방 가이드 기준

단계체감온도주요 조치
관심33°C 이상건강 상태 확인, 수분 섭취 권고
주의35°C 이상2시간 주기 휴식, 그늘 휴식공간 확보
경고38°C 이상1시간 주기 휴식, 무거운 작업 금지
위험41°C 이상즉시 작업 중지, 근로자 대피

6. 문제 해결

증상해결
현장 목록 안 보임"새로고침" 클릭 (날씨 조회에 수 초 소요)
작업자 알림 안 감작업자가 QR 스캔 → Chrome → 알림 허용 필요
"발송 대상 없음"작업자 앱에서 알림 OFF→ON 재시도
삼성 인터넷 알림 불가Chrome 브라우저로 접속
iPhone 알림 불가Safari > 공유 > 홈 화면에 추가 > 앱에서 알림 허용
엑셀 업로드 실패.xls .xlsx .csv만 지원 (10MB 이하)
