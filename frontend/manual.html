1. 시스템 개요

1.1 이 시스템은 무엇인가요?

KEPCO 안전관리 시스템은 혹서기(여름철) 폭염으로부터 옥외 작업자의 안전을 보호하기 위한 시스템입니다. 실시간으로 작업현장의 기온을 모니터링하고, 고용노동부 폭염 단계별 기준에 따라 자동으로 작업자에게 알림을 발송합니다.

1.2 주요 기능

기능 설명
실시간 날씨 모니터링 15분 간격으로 각 작업현장의 기온, 습도, 풍속을 자동 수집
체감온도 자동 계산 기온과 습도를 바탕으로 체감온도 자동 산출
WBGT 추정 습구흑구온도지수(WBGT) 간이 추정 및 작업강도별 권고
폭염 단계 판정 고용노동부 기준에 따라 관심/주의/경고/위험 4단계 자동 판정
자동 알림 발송 카카오 알림톡으로 해당 현장 작업자에게 즉시 알림
이력 관리 모든 날씨 기록과 알림 발송 이력을 데이터베이스에 저장

3. 설치 방법

  1. 프로젝트 폴더로 이동

    명령 프롬프트(CMD) 또는 터미널을 열고 프로젝트 폴더로 이동합니다.

    명령 프롬프트 cd C:\Users\KEPCO\Desktop\project\safety_manager

  2. Python 가상환경 생성

    프로젝트 전용 가상환경을 만들어 다른 프로젝트와 패키지 충돌을 방지합니다.

    명령 프롬프트 # 가상환경 생성 python -m venv venv # 가상환경 활성화 (Windows) venv\Scripts\activate # 가상환경 활성화 (Git Bash) source venv/Scripts/activate
    활성화 확인 프롬프트 앞에 (venv)가 표시되면 가상환경이 정상 활성화된 것입니다.
    예: (venv) C:\Users\KEPCO\Desktop\project\safety_manager>

  3. 필요한 패키지 설치

    시스템에 필요한 모든 Python 패키지를 한 번에 설치합니다.

    명령 프롬프트 pip install -r requirements.txt

    약 1~3분 소요됩니다. 오류 없이 완료되면 설치 성공입니다.

    사내망에서 설치 실패 시 프록시 환경이라면 아래처럼 프록시를 지정하세요:
    pip install -r requirements.txt --proxy http://프록시주소:포트

  4. 환경 설정 파일 생성

    .env.example 파일을 복사하여 .env 파일을 만듭니다.

    명령 프롬프트 # Windows 명령 프롬프트 copy .env.example .env # Git Bash cp .env.example .env

    생성된 .env 파일을 텍스트 편집기로 열어 설정값을 입력합니다. 자세한 내용은 4. 환경 설정을 참조하세요.

4. 환경 설정 (.env 파일)

.env 파일은 시스템의 모든 설정을 담고 있는 파일입니다. 메모장이나 VS Code로 열어 수정합니다.

4.1 전체 설정 항목 설명

항목 기본값 설명
APP_HOST 0.0.0.0 서버가 접속을 받을 IP (기본값 유지 권장)
APP_PORT 8000 서버 포트 번호. 다른 프로그램과 충돌 시 변경
APP_ENV development development=개발모드(콘솔알림), production=운영모드(카카오알림톡)
DATABASE_URL sqlite+aiosqlite:///./safety_manager.db 데이터베이스 접속 주소. SQLite 기본, PostgreSQL 변경 가능
KAKAO_REST_API_KEY (비어있음) 카카오 REST API 키 (운영 시 필수)
KAKAO_SENDER_KEY (비어있음) 카카오 알림톡 발신프로필 키 (운영 시 필수)
WEATHER_CHECK_INTERVAL_MINUTES 15 날씨 자동 확인 주기 (분). 5~60분 권장
HTTP_PROXY (비어있음) HTTP 프록시 주소 (사내망 시 설정)
HTTPS_PROXY (비어있음) HTTPS 프록시 주소 (사내망 시 설정)

4.2 개발 환경 설정 예시 (지금 바로 테스트용)

.env (개발용) # 개발환경 - 카카오 API 없이 콘솔에 알림 출력 APP_HOST=0.0.0.0 APP_PORT=8000 APP_ENV=development DATABASE_URL=sqlite+aiosqlite:///./safety_manager.db WEATHER_CHECK_INTERVAL_MINUTES=15 LOG_LEVEL=INFO
개발 모드에서는 카카오 API 키가 없어도 됩니다! APP_ENV=development이면 알림이 콘솔(터미널)에 텍스트로 출력됩니다. 실제 카카오 알림톡 발송 없이 시스템을 테스트할 수 있습니다.

4.3 운영 환경 설정 예시

.env (운영용) # 운영환경 - 실제 카카오 알림톡 발송 APP_HOST=0.0.0.0 APP_PORT=8000 APP_ENV=production DATABASE_URL=sqlite+aiosqlite:///./safety_manager.db KAKAO_REST_API_KEY=REDACTED_EXAMPLE_KEY KAKAO_SENDER_KEY=your_sender_key_here WEATHER_CHECK_INTERVAL_MINUTES=15 LOG_LEVEL=INFO

6. 대시보드 화면 구성

6.1 화면 구성 요소

(1) 상단 헤더

시스템명, 모니터링 동작 상태 표시등(녹색 점), 현재 시각이 표시됩니다.

(2) 폭염 경보 배너

현재 선택된 작업현장의 폭염 단계를 한눈에 보여주는 큰 배너입니다.

상태 배너 색상 설명
정상 녹색 체감온도 33°C 미만 - 정상 작업 가능
관심 노란색 체감온도 33°C 이상 - 주의 환기
주의 주황색 체감온도 35°C 이상 - 정기 휴식 필요
경고 빨간색 체감온도 38°C 이상 - 작업시간 단축
위험 진빨간색 (깜빡임) 체감온도 41°C 이상 - 작업 중지

(3) 단계 인디케이터 바

4개의 막대로 현재 단계를 시각적으로 표시합니다. 해당 단계까지 색이 채워집니다.

(4) 현재 날씨 카드

현재 기온, 체감온도, 습도, 풍속, WBGT 추정값이 표시됩니다.

(5) 조치사항 카드

현재 폭염 단계에 해당하는 고용노동부 기준 조치사항이 자동으로 표시됩니다.

(6) 작업현장 카드

등록된 작업현장 목록이 표시됩니다. 클릭하면 해당 현장의 날씨를 조회합니다.

(7) 알림 통계 카드

최근 7일간의 알림 발송 건수, 성공/실패 건수가 표시됩니다.

(8) 알림 이력 카드

최근 발송된 알림 목록이 시간순으로 표시됩니다.

7. 작업현장 등록

  1. 현장 등록 버튼 클릭

    대시보드의 "작업현장" 카드 우측 상단에 있는 "+ 현장 등록" 버튼을 클릭합니다.

  2. 현장 정보 입력

    팝업 창에서 아래 정보를 입력합니다:

    항목 필수 설명 입력 예시
    현장명 필수 작업현장의 이름 강남변전소 증설공사
    주소 선택 현장 주소 서울시 강남구 역삼동 123
    위도 필수 현장의 GPS 위도 좌표 37.5665
    경도 필수 현장의 GPS 경도 좌표 126.9780
    작업강도 필수 해당 현장의 주된 작업 강도 선택 중작업

  3. 위도/경도 쉽게 입력하기

    위도/경도를 모른다면 두 가지 방법을 사용할 수 있습니다:

    방법 1 - 현재 위치 사용: "현재 위치" 버튼을 클릭하면 지금 있는 곳의 좌표가 자동으로 입력됩니다. (현장에서 등록할 때 유용)

    방법 2 - 네이버/카카오 지도에서 확인:

    • 네이버 지도 또는 카카오맵에서 해당 현장을 검색합니다
    • 해당 위치를 마우스 우클릭 합니다
    • 표시되는 좌표를 복사하여 입력합니다

  4. 작업강도 선택 기준

    작업강도 해당 작업 예시 (KEPCO)
    경작업 계기 점검, 설비 감시, 사무작업, 경미한 수공구 작업
    중등작업 배전선로 점검, 지중케이블 접속, 변압기 점검, 애자 교체
    중작업 전주 작업, 케이블 포설, 중량물 운반, 지선 작업
    초중작업 굴착 작업, 전주 건주/철거, 대형 기자재 운반

  5. 등록 완료

    "등록" 버튼을 클릭하면 현장이 등록되고 목록에 표시됩니다. 해당 현장을 클릭하면 바로 날씨가 조회됩니다.

8. 작업자 등록

  1. 작업자 등록 버튼 클릭

    대시보드 하단 "최근 알림 이력" 카드 우측의 "+ 작업자 등록" 버튼을 클릭합니다.

  2. 작업자 정보 입력

    항목 필수 설명 입력 예시
    이름 필수 작업자 성명 홍길동
    전화번호 필수 카카오 알림톡 수신 번호 010-1234-5678
    소속 부서 선택 소속 부서/처 배전건설부
    작업반 선택 소속 작업반 1공구 3반
    취약 작업자 선택 체크 시 더 낮은 온도에서 알림 수신 체크박스

  3. 취약 작업자 체크 기준

    아래에 해당하는 작업자는 "취약 작업자"를 체크합니다:

    • 만 65세 이상 고령 근로자
    • 심뇌혈관질환 등 기저질환자
    • 폭염 작업 경험이 부족한 신규 입사자
전화번호 중복 불가 이미 등록된 전화번호로는 재등록할 수 없습니다. 기존 등록 정보를 수정하려면 API 문서(/docs)에서 PUT 요청을 사용하세요.

9. 작업자 현장 배정

등록된 작업자를 특정 작업현장에 배정해야 해당 현장의 폭염 알림을 받을 수 있습니다.

9.1 API를 통한 배정 (Swagger UI 사용)

  1. API 문서 접속

    브라우저에서 http://localhost:8000/docs에 접속합니다.

  2. 배정 API 찾기

    "작업자/현장 관리" 섹션에서 POST /api/sites/{site_id}/workers/{worker_id}를 찾아 클릭합니다.

  3. "Try it out" 클릭 후 값 입력

    site_id에 작업현장 ID, worker_id에 작업자 ID를 입력합니다.

    ID를 모른다면? 같은 페이지에서 GET /api/sites와 GET /api/workers를 먼저 실행하여 ID를 확인하세요.

  4. "Execute" 클릭

    200 응답이 오면 배정 완료입니다.

10. 날씨 및 폭염 단계 확인

10.1 대시보드에서 확인

작업현장 목록에서 현장을 클릭하면 해당 현장의 날씨가 자동 조회됩니다.

표시되는 정보:

  • 현재 기온 - 실제 대기 온도 (°C)
  • 체감온도 - 기온+습도를 반영한 체감 온도. 이 값으로 폭염 단계를 판정합니다
  • 습도 - 상대습도 (%)
  • 풍속 - 바람 속도 (m/s)
  • WBGT 추정값 - 습구흑구온도지수 추정치. 산업안전보건기준에 관한 규칙 제559조 기준 적용

10.2 자동 갱신

대시보드는 1분마다 선택된 현장의 날씨를 자동으로 갱신합니다. 수동으로 갱신하려면 "현재 날씨" 카드의 "새로고침" 버튼을 클릭합니다.

10.3 백그라운드 모니터링

대시보드를 보고 있지 않아도 서버가 15분마다(설정 가능) 모든 옥외 작업현장의 날씨를 자동으로 확인합니다. 폭염 주의 단계 이상이면 해당 현장에 배정된 모든 작업자에게 자동으로 알림을 발송합니다.

11. 알림 발송 체계

11.1 자동 발송 조건

단계 체감온도 알림 발송 여부
관심 (1단계) 33°C 이상 알림 발송 안 함 (대시보드 표시만)
주의 (2단계) 35°C 이상 알림 발송
경고 (3단계) 38°C 이상 알림 발송
위험 (4단계) 41°C 이상 긴급 알림 발송

11.2 중복 발송 방지

같은 작업자에게 같은 단계의 알림은 1시간 이내에 재발송하지 않습니다.

예: 주의 단계 알림을 09:00에 발송했다면 10:00 이전에는 같은 주의 단계 알림을 보내지 않습니다. 단, 주의 → 경고로 단계가 상승하면 즉시 발송합니다.

11.3 알림 메시지 예시

[KEPCO 안전관리] 폭염 경고 단계 ━━━━━━━━━━━━━━━━ ■ 대상자: 홍길동님 ■ 현장: 강남변전소 증설공사 ■ 체감온도: 39.2°C ■ 발령시각: 2026-07-15 14:30 ━━━━━━━━━━━━━━━━ [조치사항] - 매시간 15~20분 이상 규칙적 휴식 부여 - 14시~17시 옥외작업 최대한 자제 - 취약자 옥외작업 금지 - 작업시간 단축 검토 ━━━━━━━━━━━━━━━━ 안전이 최우선입니다. 건강에 유의하세요.

11.4 개발 모드의 알림

APP_ENV=development일 때는 카카오 알림톡 대신 서버 터미널 콘솔에 알림 내용이 출력됩니다. 카카오 API 설정 없이 기능을 테스트할 수 있습니다.

12. 수동 모니터링 (긴급 점검)

15분 주기를 기다리지 않고 지금 즉시 모든 현장을 점검하고 싶을 때 사용합니다.

12.1 대시보드에서 실행

"알림 통계" 카드의 "수동 점검" 버튼을 클릭합니다. 모든 옥외 작업현장의 날씨를 즉시 확인하고 필요 시 알림을 발송합니다.

12.2 위험 단계 긴급 알림

상단 배너가 위험(빨간색)으로 표시될 때 나타나는 "긴급 알림 발송" 버튼을 클릭하면 해당 현장 작업자 전원에게 즉시 알림이 발송됩니다.

13. 알림 이력 조회

13.1 대시보드에서 조회

대시보드 하단의 "최근 알림 이력" 카드에서 최근 20건의 알림을 확인할 수 있습니다. 각 항목에는 발송 시각, 단계, 체감온도, 발송 채널, 성공/실패 여부가 표시됩니다.

13.2 API를 통한 상세 조회

http://localhost:8000/docs에서 아래 API를 사용할 수 있습니다:

API 용도
GET /api/alerts/history 전체 알림 이력 조회 (현장 ID, 건수 필터 가능)
GET /api/alerts/stats 기간별 알림 통계 (총 건수, 성공/실패, 단계별 분포)
GET /api/weather/history/{site_id} 특정 현장의 날씨 변화 이력 조회

15. WBGT 작업강도별 기준

법적 근거 산업안전보건기준에 관한 규칙 제559조 별표14 - 고열작업 WBGT 기준

WBGT(습구흑구온도지수)는 기온, 습도, 복사열, 풍속을 종합한 지표로, 작업강도에 따라 다른 기준을 적용합니다.

작업강도 연속작업 75% 작업
25% 휴식		 50% 작업
50% 휴식		 25% 작업
75% 휴식
경작업
계기점검, 감시		 30.0°C 30.6°C 31.4°C 32.2°C
중등작업
배전선로 점검		 26.7°C 28.0°C 29.4°C 31.1°C
중작업
전주작업, 케이블 포설		 25.0°C 25.9°C 27.9°C 30.0°C
초중작업
굴착, 전주 건주		 22.8°C 25.0°C 27.1°C 28.6°C

예를 들어, WBGT가 28°C이고 작업강도가 "중작업"이라면, 연속작업(25.0°C)과 75% 작업(25.9°C) 기준을 모두 초과했으므로 "50% 작업 / 50% 휴식" 이상의 휴식이 필요합니다.

WBGT는 추정값입니다 이 시스템의 WBGT는 기온, 습도, 풍속으로 간이 추정한 값입니다. 정확한 측정이 필요한 경우 전용 WBGT 측정기를 사용하세요.

16. 취약 작업자 기준

고용노동부 가이드에 따라 아래 조건에 해당하는 작업자는 취약 작업자로 분류합니다.

구분 기준
고령자만 65세 이상 근로자
기저질환자심뇌혈관질환, 고혈압, 당뇨 등
컨디션 불량당일 건강상태가 좋지 않은 자
경험 부족폭염 환경 작업 경험이 적은 신규 입사자
전날 음주전날 과도한 음주를 한 자

취약 작업자는 주의 단계(35°C)부터 옥외작업 전환 배치 대상이 되며, 경고 단계(38°C)에서는 옥외작업이 금지됩니다.

17. 기준값 변경 방법

폭염 단계 기준 온도, WBGT 기준, 조치사항 등은 모두 config/thresholds.json 파일에서 관리됩니다. 소스코드를 수정하지 않고 이 파일만 편집하면 기준을 변경할 수 있습니다.

17.1 기준 온도 변경 예시

경고 단계 기준을 38°C에서 37°C로 변경하고 싶다면:

config/thresholds.json // 변경 전 "stage_3_warning": { "name": "경고", "apparent_temp_min": 38.0, // ← 이 값을 변경 ... } // 변경 후 "stage_3_warning": { "name": "경고", "apparent_temp_min": 37.0, ... }

17.2 서버 재시작 없이 적용

설정 파일을 수정한 후 서버를 재시작하지 않고도 적용할 수 있습니다:

  1. 브라우저에서 http://localhost:8000/docs 접속
  2. POST /api/weather/thresholds/reload API를 실행
  3. 응답에 변경된 설정이 표시되면 적용 완료
주의: JSON 형식을 정확히 지켜주세요 쉼표, 중괄호, 따옴표가 하나라도 빠지면 시스템이 오류를 발생시킵니다. 편집 시 VS Code 등 JSON 검증이 가능한 편집기를 사용하는 것을 권장합니다.

19. 카카오 알림톡 설정 (운영 환경)

실제 카카오 알림톡으로 알림을 보내려면 아래 절차가 필요합니다.

  1. 카카오 비즈니스 채널 개설

    카카오비즈니스 사이트에서 비즈니스 채널을 개설합니다. KEPCO 공식 채널이 있다면 해당 채널을 사용합니다.

  2. 카카오 개발자 앱 등록

    카카오 개발자 사이트에서 앱을 등록하고 REST API 키를 발급받습니다.

  3. 알림톡 발신프로필 등록

    카카오 비즈메시지에서 발신프로필을 등록하고 발신프로필 키(Sender Key)를 발급받습니다.

  4. 메시지 템플릿 등록

    알림톡은 사전에 승인된 템플릿만 발송할 수 있습니다. 폭염 단계별로 3개 템플릿을 등록합니다:

    • heat_caution - 주의 단계 템플릿
    • heat_warning - 경고 단계 템플릿
    • heat_danger - 위험 단계 템플릿

  5. .env 파일에 키 입력

    .env APP_ENV=production KAKAO_REST_API_KEY=발급받은_REST_API_키 KAKAO_SENDER_KEY=발급받은_발신프로필_키 KAKAO_TEMPLATE_CODE_CAUTION=heat_caution KAKAO_TEMPLATE_CODE_WARNING=heat_warning KAKAO_TEMPLATE_CODE_DANGER=heat_danger

  6. 서버 재시작

    설정 변경 후 서버를 재시작하면 실제 카카오 알림톡으로 발송됩니다.

20. 사내망 이관 방법

이 시스템은 사내망 이관을 고려하여 설계되었습니다. 아래 3가지만 변경하면 됩니다.

  1. 데이터베이스 변경 (선택)

    사내망에 PostgreSQL 또는 MySQL이 있다면 .env의 DATABASE_URL만 변경합니다:

    .env # SQLite (기본) DATABASE_URL=sqlite+aiosqlite:///./safety_manager.db # PostgreSQL (사내망 이관 시) DATABASE_URL=postgresql+asyncpg://유저:비밀번호@DB서버주소:5432/safety_manager # MySQL (사내망 이관 시) DATABASE_URL=mysql+aiomysql://유저:비밀번호@DB서버주소:3306/safety_manager
    코드 수정 불필요! Repository 패턴과 SQLAlchemy ORM을 사용하므로 DATABASE_URL만 바꾸면 모든 코드가 그대로 동작합니다. 처음 실행 시 테이블이 자동 생성됩니다.

  2. 프록시 설정

    사내망에서 외부 API(Open-Meteo, 카카오)에 접속하려면 프록시 설정이 필요합니다:

    .env HTTP_PROXY=http://proxy.kepco.co.kr:8080 HTTPS_PROXY=http://proxy.kepco.co.kr:8080

    프록시 주소와 포트는 사내 IT 담당부서에 문의하세요.

  3. 날씨 API 교체 (선택)

    사내망에서 Open-Meteo 접속이 불가능하거나 기상청 API를 사용하고 싶다면:

    1. backend/services/ 폴더에 새 파일 생성 (예: kma_provider.py)
    2. WeatherProvider 인터페이스를 구현하는 클래스 작성
    3. backend/dependencies.py 파일에서 구현체를 교체:
      # 변경 전 _weather_provider = OpenMeteoProvider() # 변경 후 _weather_provider = KmaProvider()

    마찬가지로 알림 서비스도 NotificationSender 인터페이스를 구현하면 SMS 게이트웨이 등으로 교체할 수 있습니다.

21. 문제 해결 (FAQ)

Q1. 서버가 실행되지 않아요

확인 사항:
  • 가상환경이 활성화되어 있나요? 프롬프트에 (venv)가 보여야 합니다
  • pip install -r requirements.txt를 실행했나요?
  • .env 파일이 생성되어 있나요?
  • 포트 8000이 이미 사용 중이라면 .env에서 APP_PORT=8001로 변경하세요

Q2. 날씨 데이터를 가져올 수 없어요

확인 사항:
  • 인터넷 연결을 확인하세요
  • 사내망이라면 프록시 설정을 확인하세요 (프록시 설정 참조)
  • 방화벽에서 api.open-meteo.com이 차단되어 있지 않은지 확인하세요

Q3. 카카오 알림톡이 발송되지 않아요

확인 사항:
  • APP_ENV=production으로 설정했나요? (development이면 콘솔 출력만 됩니다)
  • KAKAO_REST_API_KEY와 KAKAO_SENDER_KEY가 올바른가요?
  • 카카오 알림톡 메시지 템플릿이 승인 완료 상태인가요?
  • 수신자 전화번호가 카카오톡에 등록된 번호인가요?

Q4. 알림이 중복 발송돼요

정상 동작입니다. 같은 단계의 알림은 1시간 이내 재발송되지 않습니다. 단, 단계가 상승(예: 주의→경고)하면 즉시 발송합니다. 간격을 조정하고 싶다면 backend/scheduler/monitor.py에서 hours=1 값을 변경하세요.

Q5. 데이터베이스를 초기화하고 싶어요

주의: 모든 데이터가 삭제됩니다! 서버를 종료한 후 safety_manager.db 파일을 삭제하고 서버를 재시작하면 빈 데이터베이스가 새로 생성됩니다.

Q6. Python 버전이 맞지 않아요

Python 3.10 이상이 필요합니다.
python --version으로 확인하세요. 3.10 미만이라면 Python을 업그레이드하거나, py -3.10 등 특정 버전을 지정하여 실행하세요.
