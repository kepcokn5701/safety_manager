# 테스트용 가짜 데이터

**전부 허구 데이터입니다. 실제 개인정보 아님.**

- 이름: 소설 인물 (홍길동, 김철수 …)
- 전화번호: `010-0000-xxxx` (실존하지 않는 번호)
- 주소: 실존 도로명이지만 특정 개인·현장과 무관

## 파일

| 파일 | 형식 | 용도 |
|---|---|---|
| `테스트_사전신고_가짜데이터.xlsx` | 진짜 엑셀 | **지금 바로 업로드 테스트 가능** |
| `테스트_사전신고_가짜데이터.xls` | HTML형 .xls | 실제 사전신고 파일과 동일 형식. 단, 현재 배포본은 HTML `.xls` 파싱 라이브러리(lxml/bs4)가 없어 파싱 안 됨. `.xlsx`로 저장 후 업로드하거나, 추후 라이브러리 추가 시 사용. |

## ⚠️ 실제 개인정보 파일 취급

실제 사전신고 파일(작업자 실명·전화번호 포함)은 **저장소에 커밋하지 말 것.**
`.gitignore`가 루트의 `사전신고정보*.xls*` 및 `*.xls*`를 무시하도록 설정돼 있으며,
가짜 데이터가 있는 이 `test_data/` 폴더만 예외로 추적됩니다.
